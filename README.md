# Fixter Shop 🌿
Sitio web de Fixter Shop: moda ecológica y totalmente personalizada.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub (por ejemplo `fixter-shop`).
2. Sube todo el contenido de esta carpeta (`index.html`, `assets/`, `.nojekyll`, `README.md`).
3. Ve a **Settings → Pages**.
4. En **Source** elige **Deploy from a branch**, rama `main` y carpeta `/ (root)`. Guarda.
5. En 1 a 2 minutos el sitio queda en `https://TU-USUARIO.github.io/fixter-shop/`.

## Estructura
- `index.html`: la página completa (HTML, CSS y JS).
- `assets/`: imágenes y video optimizados.
